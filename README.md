# 轻迹（QingTrail）

首先说明：这是一款自用插件

把你在思源里留下的每一条时间记录，用时间轴、日历与统计看板重新串起，
让一天的点滴一眼看清、随时回看。

LifeLog 玩法受「叶归」插件启发，在这里非常感谢！

## 功能特性

- 时间轴串联 · 类型区分
- 日历分布 · 一眼回看
- 筛选统计 · 可视化复盘
- 仪表汇总 · 概况速览
- 右键修改 · 正文同步

## 灵感来源与致谢

LifeLog 这个玩法——用「时间 类型：内容」的短句记下时间流水，插件自动把段落标成
LifeLog 记录，再用时间轴把它们串起来回看——来自「叶归」插件的 LifeLog 功能。
轻迹是在它的思路启发下做的，这里郑重致谢。

## 使用前提

本插件用于可视化你在思源中记录的时间数据，单条记录格式为 `时间 类型：内容`
（例如 `08:30 工作：写周报`）。

## 使用方法

1. 在思源里按「时间 类型：内容」记录你的时间
2. 打开「轻迹」插件，即可查看对应的时间记录
3. 按时间范围或类型筛选，查看统计信息
4. 右键任意记录 → 修改内容，文档正文同步更新
